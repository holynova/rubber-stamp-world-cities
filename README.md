# 橡胶戳艺术印记 · 世界城市 / 十二生肖 / 二十四节气 / 爱经印契

复古手工多色橡胶戳印艺术画廊，共收录 **76 枚纯印章艺术作品**（世界城市 30 枚、十二生肖 12 枚、二十四节气 24 枚、爱经印契 10 枚）。画面剥离文字与排版干扰，仅保留最纯粹的版画雕刻图章主体与温暖陈旧米白纤维纸张质感。

## ✨ 核心互动功能

1. **📖 声音盖章与印记收集册（Stamp Passport）**：
   - 浏览时可一键“盖戳”，内置基于 Web Audio API 的逼真手工印章按压敲击音效。
   - 本地自动记录收集进度，支持一键生成并导出专属“旅行打卡明信片/手账页（PNG）”。
2. **🔖 专属藏书票工坊（Ex-Libris Studio）**：
   - 任意印章均可一键制作藏书票，自定义书主姓名、拉丁语/中文铭文（如 `EX LIBRIS`、`私家藏书`）、复古花边与底纸材质，生成 1200×1600 高清藏书票。
3. **🎨 多色系油墨调色盘（Ink Palette Filters）**：
   - 支持实时切换 6 种经典版画油墨风格：天然原色、传统朱砂（赤红）、复古靛蓝（木刻蓝）、水墨炭黑（黑白）、森系苔绿、古董焦茶。

## 🎨 收录系列

1. **世界城市（30 幅）**：精选 30 座全球名城地标、天际线与旅行手账印记。
2. **十二生肖（12 幅）**：子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪瑞兽印记。
3. **二十四节气（24 幅）**：春生、夏长、秋收、冬藏，24 幅凝结于宣纸之上的时序物候印章。
4. **爱经印契（10 幅）**：汲取东方古典雕刻、飞天壁画与莲华曼荼罗灵感，10 帧纯粹神圣的古典亲密与身心圆融版画。
